Interface disponible en français, anglais et espagnol.

- Choix de langue enregistré dans Paramètres → Général → Langue de l’interface.
- Traductions de l’interface intégrées, utilisables hors ligne.
- Descriptions et succès Steam récupérés dans la langue choisie lorsqu’ils sont disponibles.
- Système de mise à jour compatible avec le dépôt renommé Ludemis-Launcher.
- Aucun identifiant OAuth Google intégré à cette compilation ; la connexion Google Drive reste temporairement indisponible.

Cette publication fournit l’exécutable destiné à la mise à jour intégrée et son empreinte SHA-256. Les données personnelles et le cache existants sont conservés.

Important pour la 1.41 : son contrôle des liens utilise encore l’ancien nom du dépôt. Lance une fois le nouvel exécutable manuellement pour passer à la 1.42. Cette incompatibilité est corrigée pour les prochaines mises à jour.

Validation : 150 tests JavaScript, contrôles de navigation dans les trois langues, tests Go et compilation Windows réussis. L’application n’a pas été exécutée directement sous Windows dans cet environnement.
